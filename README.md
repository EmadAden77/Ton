# Ton

تطبيق ويب عربي لبناء Prompts متماسكة وواقعية لصور سيلفي داخل غرفة نوم ثابتة.

**استخدم التطبيق:** https://ton-seven-nu.vercel.app/

---

## ما يفعله التطبيق

Ton يبني وصفاً نصياً لصورة سيلفي داخل غرفة نوم ثابتة، مع التحكم في نوع اللقطة والإضاءة والملابس والشعر والوضعية وتعابير الوجه واليد الحرة.

يمكن البدء بأحد السيناريوهات الجاهزة ثم تعديل الخيارات. يمر الاختيار عبر محرك قيود يمنع التركيبات غير المنطقية في الحالات التي تحتاج قفلاً واضحاً، مثل موضع الهاتف أثناء الاستلقاء أو في سيلفي المرآة.

التطبيق يبني النصوص فقط. الصورة المرجعية حالياً إعداد نصي يحدد ما إذا كان الـPrompt سيطلب الحفاظ على هوية مرجعية، ولا توجد عملية رفع صورة أو توليد صورة داخل التطبيق الرئيسي.

---

## المخرجات

- **Prompt (English):** الوصف الأساسي القابل للنسخ إلى أدوات توليد الصور.
- **Prompt (العربية):** نسخة عربية لفهم المشهد ومراجعته.
- **Negative Prompt:** قيود مرتبطة بالواقعية واليد والانعكاسات والوضعية، وتظهر قيود الهوية فقط عند تفعيل وجود صورة مرجعية.

---

## مبادئ الواقعية

- الغرفة ثابتة هندسياً بدلاً من إعادة اختراع غرفة مختلفة مع كل Prompt.
- الإضاءة منفصلة عن وصف الغرفة حتى لا يتعارض وصف الأثاث مع نمط الضوء المختار.
- وضع الهاتف والذراع يتغير بحسب نوع اللقطة والوضعية، خصوصاً الاستلقاء وسيلفي المرآة.
- السيناريوهات الجاهزة تثبت افتراضاتها الأساسية حتى لا تتسرب إليها إعدادات سيناريو سابق.
- الأولوية للتماسك والسببية الفيزيائية قبل زيادة طول الـPrompt.

---

## السيناريوهات الجاهزة

يوجد حالياً 8 سيناريوهات:

- العمل على لابتوب في المكتب.
- الجلوس على السرير مع اللابتوب.
- سيلفي أمام المرآة.
- الاستعداد للخروج.
- الاستلقاء على السرير والتقاط سيلفي.
- الوقوف قرب النافذة.
- اختيار ملابس من الخزانة.
- تعديل الملابس قبل الخروج.

كل Preset يحدد نوع اللقطة والمسافة والوضعية وموضع الهاتف والعناصر المرتبطة به عند الحاجة، ثم يمكن للمستخدم تعديل الخيارات بعد ذلك.

## المحاكي 3D

المسار `/3d` يقدم معاينة تجريبية للغرفة والوضعيات والإضاءة باستخدام React Three Fiber وThree.js. المحاكي مساعد بصري وليس محرك توليد صور أو محاكاة بصرية دقيقة للكاميرا.

---

## التقنية

- Next.js 15 وفق نطاق الإصدار الموجود في `package.json`.
- TypeScript وTailwind CSS.
- React Three Fiber وThree.js للمعاينة ثلاثية الأبعاد.
- Vitest للاختبارات.
- ESLint وPrettier لفحوص الجودة والتنسيق.
- GitHub Actions لتشغيل lint وtypecheck والاختبارات وفحص التنسيق.
- Vercel للاستضافة.

## التشغيل المحلي

يتطلب Node.js 22+ وnpm.

### Linux / macOS / Windows

```bash
git clone https://github.com/EmadAden77/Ton.git
cd Ton
npm install
npm run dev
```

افتح `http://localhost:3000`.

### Android / Termux

```bash
git clone https://github.com/EmadAden77/Ton.git
cd Ton
npm install
npm run dev -- --webpack
```

استخدم `--webpack` في بيئات Termux التي لا يدعم فيها Turbopack معمارية الجهاز المستخدمة.

## فحوص الجودة

```bash
npm run lint
npm run typecheck
npm run test
npm run format:check
```

ويشغّل GitHub Actions نفس فحوص الجودة على الفروع وطلبات السحب.
